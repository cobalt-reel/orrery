# The link Implementation Plan

**Goal:** a session of one primary orrery and satellites on other machines (spec: `docs/plans/2026-10-27-link-design.md`;
read it first, and section 3 of `docs/plans/2026-10-26-orrery-design.md`).

**Architecture:** a pure session table (`src/session.rs`) owned by the primary decides machines, monitor order and
workspace numbers; each machine's `Stacks` keeps its own windows and is told which numbers are its own. The link
(`src/link.rs`) is Noise over TCP with length-prefixed frames, driven from calloop. Everything new is testable headless
with orrerys linked over loopback.

**Tech stack:** Rust 2024, Smithay 0.7/calloop, `snow` (new dependency: Noise), serde_json frames.

**Ground rules for every task**
- TDD: write the failing test first, see it fail, then implement.
- Match the surrounding code: terse explanatory doc comments (≤120 columns), same naming, no other new deps.
- Before committing: `cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test` (full suite).
- orrery stays clean: no references to any other project, person, machine or personal setup.
- Tests never touch real user paths, and never listen on anything but loopback.

---

### Task 1: numbers owned elsewhere (`src/stacks.rs`) and the session table (`src/session.rs`)

- `Stacks`: screens can be given their number from outside (`add_monitor_numbered(name, area, layout, number)`;
  `renumber_workspace(from, to)` for join collisions; a set of numbers **owned elsewhere** that local `workspace(n)` /
  `move_to_workspace(n)` must not create: they return a typed outcome (`Remote(n)`) instead of acting). Alone (no
  link), behaviour is exactly today's. Unit tests + random walk keeps the invariants with foreign numbers.
- `session.rs` (pure): machines (name, link state), the monitor order (primary's first, satellites in join order),
  which machine owns each workspace number, join (keep free numbers, collisions → lowest free, returns the renames
  for the satellite), drop (frees the machine's numbers, removes its monitors), where `workspace N` goes (local, a
  machine, or "create on the focused monitor's machine" with a fresh number), cross-machine move refusal. Fully
  unit-tested, incl. drop then rejoin keeping numbers and a collision on rejoin.

Commit `session: numbers owned across machines`.

### Task 2: the link (`src/link.rs`)

- Secret file: read, refuse if group/other can read it (error names the path), never log the contents.
- Noise `NNpsk0_25519_ChaChaPoly_BLAKE2s` via `snow`; frames = u32 length + Noise ciphertext of a JSON message; size
  cap; a handshake that fails or a frame that does not decrypt closes the connection.
- Messages (serde): Hello {version, name, screens, workspaces}, Welcome {renames, session table} / Refused {reason},
  WorkspaceState, SessionTable, Command {request}, CommandAnswer {response}, Ping/Pong.
- Non-blocking state machines for both ends usable from calloop (feed bytes in, get frames/messages out), so tests
  can drive them with in-memory pipes and real loopback sockets.
- Tests: handshake + round trip; wrong secret fails with nothing in clear (check no plaintext bytes of a known message
  appear on the wire); version mismatch refused with the reason on both ends; oversize frame refused; permissions.

Commit `link: Noise frames over TCP`.

### Task 3: wiring it into orrery

- Config: `listen`, `primary`, `name` (unit tests; `orrery check` reports them).
- Primary: listener in calloop, one link per satellite, session table, `workspace N` routed (local / remote / create),
  `move-to-workspace` refused across machines, `orrery msg --to MACHINE …` forwarded and answered, `state.session`
  (machines, monitors, workspaces, latency_ms), ping every 2 s.
- Satellite: connect with backoff (≤5 s), hello, apply renames and the session table (foreign numbers), report its
  workspace state on change, run forwarded commands; on drop keep numbers, clear foreign numbers, keep reconnecting.
- e2e (`tests/link.rs`): two headless orrerys (temp secrets, loopback port 0) — join and numbering, `workspace 2` on
  the primary shows the satellite's workspace and moves the session focus, `--to` spawn/state, cross-machine move
  refused, wrong secret refused, version mismatch, duplicate name, kill the primary → satellite keeps working and its
  numbers, restart → rejoin with numbers kept; collision on rejoin.
- README: the link section (config lines, the secret file, `--to`, an ssh reverse tunnel as one way to cross firewalls),
  `state.session`.

Commit `link: primary and satellites`.

### Task 4: as built

Full suite, clippy, fmt, cleanliness scan, README vs design, "As built" section. Then the live two-machine test by hand.
